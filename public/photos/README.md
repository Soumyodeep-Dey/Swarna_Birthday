# Your photos go here

Add 10 to 20 JPG, JPEG, PNG, WebP, or AVIF images directly in this folder.
Name them 01.jpg, 02.jpg, 03.jpg, etc. to choose the order. The first photo
becomes the full-screen birthday background. Choose a portrait with some
space around her face. Use JPG or WebP under about 1 MB for fast phone loading.

The website finds images automatically at build time. After adding pictures,
restart the dev server or rebuild, then commit and push to trigger Vercel.
Only the first 20 images appear. HEIC is not supported: export it as JPG first.
Customize matching captions in src/content.ts.

Anything deployed here is publicly accessible. Use pictures you are both
comfortable sharing and prefer a private GitHub repository for the source.
